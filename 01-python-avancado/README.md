# Python avançado

Primeira área da disciplina, que corresponde ao módulo 10794, Programação avançada com Python. Começa em programação orientada a objetos e vai até uma pequena API web, sempre em Python.

| # | Assunto | Guia | Laboratório | Ficha |
| --- | --- | --- | --- | --- |
| 03 | Objetos, composição e comportamento | [guia](03-objetos-e-composicao.md) | [laboratório](03-objetos-e-composicao-laboratorio.md) | [ficha](03-objetos-e-composicao-exercicios.md) |
| 04 | Exceções, depuração e logging | [guia](04-excecoes-depuracao-e-logging.md) | [laboratório](04-excecoes-depuracao-e-logging-laboratorio.md) | [ficha](04-excecoes-depuracao-e-logging-exercicios.md) |

A numeração segue a planificação da área, mas os temas não se dão por ordem de número. As aulas começaram pelo 03, e o 04 vem a seguir. O tema 01, o diagnóstico, não é dado em aula: o enunciado está em `avaliacoes`, para quem o quiser fazer. O tema 02, o Python idiomático, vem depois do tema dos testes, porque é feito sobre o código do ginásio já testado.

Cada tema tem até três documentos com o mesmo número. O guia é para ler e estudar: tem a teoria e os exemplos explicados até ao fim. O laboratório tem os passos para seguires no computador, com o guia aberto ao lado. A ficha tem exercícios para fazeres sem ajuda, e só traz os enunciados, porque a ideia é tentares antes de veres como se faz. As resoluções são trabalhadas em aula com o professor.

Os guias são preparados com antecedência, e podes lê-los antes de a matéria ser dada nas aulas.

O código completo dos exemplos dos guias está na pasta `exemplos/python-avancado`, na raiz deste repositório. O exemplo das aulas é o dos Pokémon, que cresce de tema para tema, com cada versão numa pasta própria em [exemplos/python-avancado/pokemon](../exemplos/python-avancado/pokemon/). A do tema 03 é a pasta `03-objetos-e-composicao`, e a do tema 04 é a pasta `04-excecoes-depuracao-e-logging`, que acrescenta as exceções do ginásio e o registo dos combates. Os programas curtos mostrados na aula das dataclasses, que correm sozinhos, estão em [exemplos/python-avancado/aula-dataclasses](../exemplos/python-avancado/aula-dataclasses/README.md).
