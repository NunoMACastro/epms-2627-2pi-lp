# SQL, fundamentos

Nesta área guardas os dados de um problema numa base de dados PostgreSQL, desenhas as tabelas e fazes-lhes perguntas em SQL. Corresponde ao módulo 10788, Fundamentos da linguagem SQL. Cada tema tem estes documentos:

- o guia, com a matéria por escrito, para estudares;
- o laboratório, para fazeres no computador, passo a passo;
- a ficha de exercícios, para treinares sozinho.
